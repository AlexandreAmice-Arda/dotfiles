# Wallpaper provenance

The six Tokyo Night wallpaper assets in
`private_dot_local/share/tokyo-night/wallpapers` were created for this dotfiles
repository on 2026-09-15 with OpenAI's built-in image generation tool. They
contain no third-party source imagery.

## Landscape prompts

**Midnight:** Create a polished abstract desktop wallpaper in a Tokyo Night
visual language, 16:10 landscape. Use deep navy and ink-purple space with
layered geometric ribbons, circles, tiny sparkles, and subtle grain. Keep the
center visually quiet for terminal readability. Main palette: `#1a1b26`,
`#24283b`, `#7aa2f7`, `#7dcfff`, with restrained pink and purple accents. No
text, logos, recognizable objects, UI, or watermark.

**Dusk:** Create a companion 16:10 abstract Tokyo Night wallpaper with the same
geometric language, softened grain, and quiet center. Shift the atmosphere to
deep plum and warm violet with restrained magenta, coral, and amber edge
accents. No text, logos, recognizable objects, UI, or watermark.

**Dawn:** Create a companion 16:10 abstract Tokyo Night wallpaper with the same
geometric language, softened grain, and quiet center. Shift the atmosphere to
lavender-blue with cyan and pale-yellow highlights while retaining dark-enough
contrast for a desktop. No text, logos, recognizable objects, UI, or watermark.

## Portrait variants

Each landscape source was re-composed as a native 10:16 portrait wallpaper,
preserving its palette, grain, geometric visual language, and calm center.
Elements were redistributed for the tall canvas rather than simply cropped.
The edit prompts also prohibited text, logos, recognizable objects, UI, and
watermarks.
